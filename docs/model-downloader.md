# Desktop model downloader (D4)

`CassiniModels` supplies the pinned installer used by the optional Parakeet row.
Whistle remains bundled and selected by default. Only an explicit Download
starts runtime requests; constructing a downloader and opening Settings/About
make no network requests. Whistle and Silero build pins and the speech pipeline
remain unchanged.

The app locates model data with `ModelStorage.appData` (Foundation Application
Support / Cassini; container-relative in sandbox builds). The service receives
access to that directory by bookmark and uses `ModelDownloader(appData:userAgent:)` with
an explicit `(id, sourceSHA256)`. `plan` fetches schema-v2 manifest metadata;
`spaceRequired` quotes and checks compressed + decoded staging + bounded metadata
space while preserving max(1 GiB, 2% of volume). `install` repeats the check
immediately before writing artifacts. Existing revisions stay in place.

Only https://dist.gocassini.com is permitted in production. There are no cookies,
credential storage, HTTP cache or redirects, and requests use Accept-Encoding:
identity and, on every request including a redirect hop, the User-Agent
`CassiniTalk/<marketing version> (macOS <version>; <arch>)` (D54), built once by the
app layer with `ModelUserAgent.app()`; no person or device identifiers. Each immutable compressed object has its compressed SHA as ETag.
A bounded partial resumes using Range and If-Range; a full 200 replaces it,
416 retries once from zero, and an invalid ETag/range is discarded. Transport
interruptions retain a partial; an invalid compressed hash is never decoded.

The static decoder is Zstandard 1.5.7 (BSD-3-Clause), pinned under
Sources/CassiniZstd. It supports the manifest's concatenated frames/skippable
seek table, with a 128 MiB window limit and exact raw output size/hash checks.
All model files and fetched NOTICE.txt are synced in a private staging directory
before one exclusive rename publishes the revision. Per-revision and global
download locks serialize publication and prevent concurrent reserve overcommit.
Cancel retains resumable downloads. Remove cancels and waits, retires the whole
installed revision, and clears that pin's partials. A new install cannot race
Remove in the same downloader.

Each download ships the current bounded dist NOTICE in its installed revision.
About keeps its native menu and panel and always links bundled engine/decoder
licences. The catalog link “Licences of downloaded models” appears only while
a downloaded revision is installed, opening its local full NOTICE (D15.1).
Bundled Whistle does not make this conditional link appear. About does not
check for updates or fetch anything. No unused model rows, update bullet or
voice/speaker downloads are included.

Run `python3 scripts/verify-model-vendor.py` and
`swift test --filter ModelDownloaderTests`. The Python server binds 127.0.0.1
only. Committed deterministic generated bytes are seekable Zstd fixtures, not
models. Tests cover full and lengthless HTTP, interruption/Range/If-Range,
ignored Range, 416, changed ETag, malformed Content-Range, both bad hashes,
malformed zstd/raw bounds, disk reserve, pin mismatch, cancellation/Remove,
atomic visibility, unsafe paths/symlinks, redirect rejection and notices.
No fixture test contacts dist. `Fixtures/make.py` optionally regenerates the
objects with a local zstd CLI; CI uses committed bytes and needs no zstd install.

The Mac-only loopback initializer and disk-budget injection are internal module
interfaces used by tests, unavailable to the app's production downloader caller.
The direct Settings app probe first re-signs the generated Debug host with
`codesign --force --sign - --options 0 --timestamp=none --entitlements
Cassini/Cassini.entitlements APP`. Its script verifies the exact profile before
launch: it must not rely on the extra read-root/test-manager entitlements Xcode
injects for UI testing. This does not grant any device or OS permission.

Both architecture builds are useful; an Intel compile is not an Intel execution.

Hosted downloader jobs run the same local HTTP fixtures on ARM and Intel,
restoring the D20 producer test bundles with `--skip-build`. Original PR paths
are recorded in `.github/ci/paths.json`; main, nightly and central dispatch run
the full matrix. The reusable area also supports standalone dispatch.

The Settings app has no network-client entitlement. Networking lives in a
separate XPC download service with an explicit model-directory bookmark,
preserving network denial for the UI and its sandbox-inheriting speech workers.
See `parakeet-runtime.md` for the service boundary and per-job model leases.
The standalone downloader tests remain local HTTP fixtures.
