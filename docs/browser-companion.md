# Browser companion and owned recording sessions

The app starts the protected native-messaging broker when launched. Connect sends only two bookmarks for the exact bundled audio/control host executables to CassiniBrowserSetup.xpc. The helper validates them against its own containing app and installs the four supported Chromium browser manifest pairs. The parent app entitlement profile is unchanged. A successful installer RPC is not a connected browser: the UI waits for the management hello/status handshake.

Record starts each reconciled active browser call independently. Native standalone recording uses the same owned-session collection when no browser call is available. Each meeting has its own UUID, folder, microphone choice, input lifetimes, audio admission, clock and finalization. A recording-page Stop addresses that meeting; global controls and Quit stop all. One failed start offers a targeted retry and leaves successful meetings recording. If no audio could start, a newly created untouched empty folder is removed before becoming a Library entry. Producer intent is announced before directory creation so a concurrent scan cannot mistake preparation for an abandoned recording.

Me / The others / Both drain disabled native inputs before recording the transition. Resuming creates a fresh track span. A denied or failed microphone leaves available remote/system audio recording. Returning from the microphone privacy settings retries only the failed microphone. Browser loss retains the same folder and microphone and requests system audio only while The others is selected. Reconnection reconciles the existing interrupted capture; it does not restore browser capture or create a duplicate recording. Actual source changes are persisted using S-6 events; the fallback notification is emitted only after system samples are admitted. Browser sources remain the pre-mute page sources of the shared extension; this change makes no new claim about the native system tap's mute behavior.

Per-volume disk budgets sum rates across concurrent meetings. Reserve exhaustion stops and keeps the affected meetings and retains the explanation after saving. Shutdown closes new admission, drains inputs and in-flight factories, coalesces browser/user finalizers, and awaits empty-folder cleanup. A timed-out browser tail is marked as interrupted instead of presented as a fully flushed recording.

## Verification

Swift tests use generated PCM, private folders and the production owner/control/lifecycle classes. They cover independent profiles sharing a tab id, selection spans, permission denial/retry, late callbacks, native failure isolation, recovery, concurrent finalizers, capture intent visibility, source events and summed disk rates. The catalog is vendored byte-for-byte from coordination c74460b, including the approved microphone and generic/meeting-specific start errors.

`scripts/test-browser-capture-app.py` runs only on disposable GitHub-hosted runners. It launches the signed Debug product with the unchanged parent entitlements, actual bundled native-messaging host processes, private broker FIFOs and RAM-only native inputs. It exercises the product collection, Library visibility, per-meeting Stop, fallback/reconnect, auto-start, notification Stop routing, partial retry, denied microphone, disk reserve and no-audio cleanup. It never opens browser profiles or audio devices. The notification test exercises the delegate route without presenting a real notification. Debug fixtures and their entry point are absent from Release.

The existing ARM/Intel setup tests also exercise the signed production XPC service with private fixture browser directories. Hosted UI tests capture companion-setup.png and what-is-recorded.png at 1120 by 720 alongside every existing board. Full app builds, signatures and UI launch are validated by hosted CI. Local checks are compiler checks, SDK unit tests, framing vectors and Node VM tests only. Real browser/device/permission behavior still requires a separately authorized disposable desktop run; this work does not dismiss or bypass TCC prompts.
